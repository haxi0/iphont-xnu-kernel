# Development script migration inventory

Source inventory dated 2026-10-26. Scope: project-owned scripts/modules in both repository indexes, plus visible new host scripts. Downloaded third-party source/build trees and device backups are excluded. Each row was inspected for its header/docstring and imports or named external interfaces; this is a **static inventory, not a claim of behavioral parity**. Full per-script execution/recovery validation is still required before deletion.

**No legacy script is authorized for deletion yet.** The replacement mailbox/boot/control path has not been validated on hardware, and the owner deferred a loader reload. `xl` still owns unique selftest/hang/reload and recovery behavior. `tools/t` has driver/power/rendering scenarios that `iphont test device` does not replace. Build drivers, APFS tooling, converters, firmware extraction, QEMU, and installation/key/backup utilities remain explicit infrastructure.

| Area | Replacement/evidence | Disposition |
|---|---|---|
| `xl` screenshots and console | Native Python capture/parser exercised on physical phone; staged-buffer locks fixed in both tools | Retain whole script until every command/environment and recovery behavior passes parity |
| `xl` run/boot/resident image/install/health | Python implementation exists; new RAM workflow hardware validation deferred | Retain; do not flash to test parity |
| `tools/t`, scenario scripts | Host checks remain useful; native smoke tests are read-only and narrower | Retain all unique scenarios |
| Build/image/firmware/key/recovery scripts | Reused explicitly, not claimed replaced | Retain |
| Capture converters | `iphont capture` still invokes these existing Python decoders; ffmpeg remains explicit | Retain until native migration and format tests |
| New `tools/iphont` modules/tests | Current implementation | Keep |
